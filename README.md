# Serena
  O Serena é um site de organização pessoal desenvolvido para ajudar os usuários a planejarem sua rotina de forma simples, prática, leve e visualmente agradável. O site permite organizar tarefas, acompanhar hábitos, visualizar compromissos no calendário e registrar anotações, incentivando e construindo uma rotina mais equilibrada, tranquila, produtiva e organizada.
